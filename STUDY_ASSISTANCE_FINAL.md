# Study Assistance (Zero AI API)

The student AI Tutor portal is now a rule-based Study Assistance workspace. It does not call an AI provider.

Features:
- Course/topic/lesson search
- Continue learning
- Today's study plan
- Revision center with spaced-repetition flashcards
- Wrong-answer review
- Weak-topic analysis from quiz results
- Notes and bookmarks surfaced in the study flow
- Quick practice using the existing adaptive test
- Performance summary
- Study history
- Focus timer
- Browser/device speech support where available
- Mobile-first study layout

Existing courses, quizzes, flashcards, notes, bookmarks, analytics, leaderboard, library, certificates, notifications and admin features remain available.
