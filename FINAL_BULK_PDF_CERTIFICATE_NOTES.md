# Final Bulk PDF + Certificate Integration

Expo SDK 54 React Native frontend.

Admin:
- Course Builder -> Bulk PDF Import
- Course PDF -> draft course/modules/lessons
- Quiz PDF -> draft quiz/questions

Student:
- Certificates screen is student-only through AppNavigator role routing.
- Completed courses can generate certificates.
- Issued certificates can be downloaded as PDF.

Run: npm install && npx expo start
