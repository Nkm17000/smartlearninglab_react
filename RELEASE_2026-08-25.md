# Smart Learning Lab Frontend Release — 2026-08-25

This release is based on the supplied `smart_learning_lab_react_native (2)(1)` source.

### Fixed
- Admin Learning Library file upload now preserves the browser `File` object and sends valid multipart data.
- Course resource upload uses the same cross-platform upload helper.
- Lesson resource upload uses the same cross-platform upload helper.
- `BASE_URL` is exposed through the API facade for resource-opening/download helpers.

### Build
`npm ci && npm run build:web`

The source package intentionally excludes `node_modules`, `.git`, Expo cache and stale `dist` output.
