# Resource UI update

- Course/lesson builder no longer embeds the full resource upload form.
- Admin sees an `Upload Resource` button only.
- Clicking it opens the full resource manager view.
- Course resources are shown at the end of the course only when at least one exists.
- Lesson resources are shown compactly only when at least one exists.
- Existing backend resource APIs are reused; no backend endpoint changes are required for this UI update.
